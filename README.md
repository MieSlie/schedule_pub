#  Персонализированное расписание для ВУЗа.<br>WEB-приложение + Telegram бот. 
Цель проекта - создание WEB-приложения, которое автоматизирует процесс парсинга Excel-файлов и предоставляет каждому пользователю персонализированный доступ к расписанию через интуитивно понятный интерфейс.

## Ключевые функции
#### Импорт и обработка данных
- Интеллектуальный парсер Excel: Автоматическое извлечение данных о дисциплинах, преподавателях, аудиториях, типах занятий (лекция, практика, лабораторная) и подгруппах из файлов формата .xls / .xlsx.
- Валидация и защита от дубликатов: Перед добавлением записи в базу данных система проверяет её наличие по всем ключевым атрибутам, предотвращая дублирование пар.
- Обработка сложных случаев: Парсер корректно распознает:
- Пары с двумя преподавателями или двумя аудиториями в одной ячейке.
- Несколько дисциплин в одной ячейке.
- Нестандартные форматы написания ФИО преподавателей (с дефисом, инициалами).
- Визуализация ошибок: При обнаружении проблемных ячеек (например, более двух преподавателей) система делает скриншот (excel2img) и отправляет его администратору для быстрой ручной корректировки.
- Пакетная загрузка: Возможность обрабатывать более 50 файлов за раз с контролем лимитов Telegram API.

#### Поиск и фильтрация
- Мультикритериальный поиск: Формирование расписания одновременно по нескольким параметрам: преподаватель, группа, аудитория, день недели, номер пары, корпус.
- Умный ввод (Live Search): Поиск совпадений по словарю команд начинается после ввода первых 3 символов, что снижает нагрузку на клиент и ускоряет работу.
- Автоматический режим: Система динамически определяет наиболее подходящий формат отображения (сводная таблица) на основе количества выбранных критериев (например, если выбрано 3 преподавателя — покажет сравнительную таблицу).
- Выбор недели: Переключение между учебными неделями с автоматическим определением текущей недели по системной дате.

#### Визуализация расписания
- Стандартная сетка 8x6: Классическое отображение пар (8 строк) по дням недели (6 столбцов).
- Сводные таблицы: Режимы сравнения расписаний для нескольких преподавателей, групп или аудиторий одновременно (6 таблиц по дням недели).
- Подсветка текущей пары: Автоматическое выделение пары, которая идёт в данный момент, на основе текущего времени.
- Адаптивная верстка: Корректное отображение на смартфонах, планшетах и десктопах (Tailwind CSS + медиа-запросы).
- Сообщение о пустом результате: Понятный вывод «НИЧЕГО НЕ ВЫБРАНО» при отсутствии данных по запросу.

#### Навигация
- Прямые ссылки (Deep Linking): Каждое сформированное расписание имеет уникальный URL, который можно сохранить в закладки или отправить коллеге/одногруппнику.
- Работа без регистрации: Доступ к системе открыт для любого пользователя без создания аккаунта.

#### Безопасность
- Защита от SQL-инъекций: Все запросы к базе данных параметризованы.
- CSRF-защита: Встроенные механизмы Flask для защиты форм.
- Контейнеризация: Изоляция зависимостей через Docker.


## Технологический стек
### Backend:

Python 3.12 — основной язык разработки.

Flask — микрофреймворк для маршрутизации и обработки запросов.

SQLite — встраиваемая реляционная БД.

Jinja2 — шаблонизатор для генерации HTML.

Aiogram — асинхронная библиотека для интеграции с Telegram API.

xlrd / openpyxl / excel2img — библиотеки для парсинга Excel и визуализации ошибок.

### Frontend:

HTML5 — семантическая разметка.

Tailwind CSS — утилитарный CSS-фреймворк для быстрой и адаптивной верстки.

JavaScript — динамическое взаимодействие (фильтрация, обработка ввода без перезагрузки страницы).
